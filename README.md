# 우리의 드리미 나이츠 v4.11 공개 테스트 배포본

이 폴더는 다른 사람이 웹에서 플레이해볼 수 있도록 정리한 공개 테스트용 정적 웹 게임입니다.

## 실행 파일

- 시작 파일: `index.html`
- 필수 폴더: `assets`
- 구성 파일: 루트의 `.js`, `.css`, `icon.svg`

## 배포 방법

정적 웹 호스팅에 이 폴더의 내용을 그대로 업로드하면 됩니다.

권장 방식:

1. Netlify Drop 또는 Vercel에 폴더 전체를 업로드
2. GitHub Pages를 사용할 경우 이 폴더의 내용을 저장소 루트에 배치
3. 사내 또는 개인 웹서버를 사용할 경우 `index.html`이 루트에서 열리도록 업로드

## 공개 전 확인

- 업로드 후 첫 화면에서 인트로가 정상 재생되는지 확인
- 아리와 포포 중 캐릭터 선택이 가능한지 확인
- 키보드 조작과 모바일 터치 버튼이 보이는지 확인
- 사운드가 자동 재생되지 않고 사용자의 조작 후 켜지는지 확인

## 다음 작업 메모

다음 개발 단계는 플레이 완성도 개선입니다. 이동, 사다리, 대시, 몬스터 겹침, 타격 판정, 모바일 조작을 먼저 다듬고, 이어서 시나리오별 몬스터 일러스트와 미션맵 전용 몬스터를 추가합니다. 난이도는 너무 높지 않게 유지하되, 몬스터마다 개성 있는 공격 준비 동작과 타격 반응이 드러나도록 개선합니다.
