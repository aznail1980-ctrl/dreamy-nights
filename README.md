# 우리의 드리미 나이츠 v4.27.0 공개 테스트 배포본

이 폴더는 다른 사람이 웹에서 플레이해볼 수 있도록 정리한 공개 테스트용 정적 웹 게임입니다.

## 바로 플레이

- 공개 게임: https://aznail1980-ctrl.github.io/dreamy-nights/
- 권장 환경: 최신 Chrome, Edge, Safari
- PC는 키보드, 모바일은 화면의 터치 버튼으로 조작할 수 있습니다.

## 실행 파일

- 시작 파일: `index.html`
- 필수 폴더: `assets`
- 구성 파일: 루트의 `.js`, `.css`, `icon.svg`

## 현재 배포

- v4.27.0: 아리/포포의 일반·내려찍기·모은 공격 효과음을 구분하고, 무기 등급과 강화 +0~+5에 따라 타격 소리·빛·궤적이 달라집니다. 공격 중 게임이 멈출 수 있던 옛 음향 호출도 수정했습니다. 모바일 가로 화면의 정보/버튼 배치·노치 여백·화면 회전을 보완했으며, 장면 비율과 최소 44px 터치 영역을 유지합니다. [공격음 비교](audio-room.html?v=4.27.0)에서 직접 들어볼 수 있습니다. 실제 휴대폰 하드웨어 검수는 남아 있습니다.

- v4.26.1: 달리기·점프 때 모자/왕관/리본이 원화의 머리 위치·기울기·크기를 따르도록 보정했습니다. 가방/등불의 등 부착점과 망토 기울기도 보정하고, 캐릭터 수첩에서 걷기와 달리기를 따로 확인할 수 있습니다. 기존 장착·소유 정보는 유지됩니다.

- v4.26.0: 맵별 음악 10곡, 녹음 기반 효과음 41개와 몬스터 11종의 공격 발성, 재질별 타격 변주, 음악·효과음·대사 음량 분리를 적용했습니다. [소리 감상실](audio-room.html)에서 듣고 원작자·이용 조건을 확인할 수 있습니다. 기존 전용 음성 83개는 유지하며, 녹음이 없는 최신 대사 14개는 자막으로 진행합니다. NPC 연기 품질 개선은 아직 완료하지 않았으며 전문 음성 제작 방식을 검토 중입니다.

- v4.25.0: 물결수달·새잎여우·별아가미의 어린/성장 동작 원화 48컷, 거리 기반 보행, 눈 깜빡임·점프·인사를 적용했습니다. 정지 중 미끄러짐과 제자리 방향 전환 때 펫이 앞뒤로 왕복하는 행동을 줄였습니다. 기존 펫 저장은 유지됩니다.

- v4.24.1: 아리/포포의 크림색·파도결 스카프가 가슴 앞에 떠 있던 문제를 수정했습니다. 목 전용 위치, 모으기/강공격의 원화 좌표, 측면/뒷면 방향 및 앞뒤 레이어를 적용했습니다.

- v4.24: 캐릭터·가방·꾸미기·성장 공통 메뉴, 종류/장비 부위/등급/보유 필터, 상세 하단 장착·제작 버튼을 적용했습니다. 휴대폰은 목록/상세를 분리하며 실제 착용 모습과 재료 보유/필요량을 확인할 수 있습니다. 기존 장비·펫·성장 저장은 유지됩니다.

- v4.23: 캐릭터 → 꿈빛 성장(U)에서 공격·보호·제어 트리를 배웁니다. 선택 스킬1개(K)·공명기1개(F)·자동 특성2개이며, 항구와 가까운 야영지에서 무료로 다시 배울 수 있습니다. 의뢰·탐험 경험치, 첫 나라 성장 포인트5개와 기존 레벨/장비/펫 보존을 적용했습니다.

- v4.22: 아리·포포의 달리기/점프와 첫 나라 몬스터 11종에 동작 시트 7장·50컷을 추가했습니다. 실제 이동 거리와 발걸음을 맞추고 공중에서 맞은 몬스터가 자연스럽게 떨어지도록 보완했습니다.
- v4.21: 이단 점프와 공중 내려찍기(키보드·터치 공통).

- v4.20: 첫 세계 15개 의뢰의 연결 조건 보완, 5개 지역의 개별 동선, 엔딩 이후 오븐 마을 출항 준비 3단계, 순찰 가방 재구성 및 로비 박스 겹침 수정. 실제 몽글 오븐 마을 지역은 아직 열리지 않습니다.

- v4.19: 선택한 캐릭터의 성격·무기·입단 사연·작은 비밀을 읽고, 선택할 때마다 고유 인사 모션과 별빛 반응을 볼 수 있습니다. 모바일은 소개를 스크롤해 읽는 동안 시작 버튼을 하단에 유지합니다.

v4.18: 눈을 깜빡이고 인사하는 아리·포포와 새 인트로/시작 버튼. 캐릭터를 누르면 인사하고, 상단 모션 버튼에서 움직임을 멈출 수 있습니다. [로비 개선·그림·검사 기록](LOBBY-v4.18.md).

v4.17: 가방의 기억 수선대에서 개별 장비 강화·잠금·분해를 지원합니다. 캐릭터 화면 또는 P키에서 꿈의 알과 펫 3종을 돌볼 수 있습니다. 기존 저장은 자동으로 이전합니다. 자세한 수치와 범위는 [성장 기능 안내](GROWTH-v4.17.md)를 참고하세요.

`main` 브랜치의 루트가 GitHub Pages에 자동 배포됩니다. 새 버전을 반영할 때는 배포 파일을 교체하고 `main` 브랜치에 올리면 됩니다.

## 공개 전 확인

- 업로드 후 첫 화면에서 인트로가 정상 재생되는지 확인
- 아리와 포포 중 캐릭터 선택이 가능한지 확인
- 키보드 조작과 모바일 터치 버튼이 보이는지 확인
- 사운드가 자동 재생되지 않고 사용자의 조작 후 켜지는지 확인

## 다음 작업 메모

최근 변경은 [개발 기록](DEVELOPMENT.md), 전체 누적 요청의 상태는 [전체 과제](NEXT-TASKS.md)에 정리했습니다. 모든 요청이 완료된 버전은 아닙니다.

## 저장·거래 회귀 검사

Node.js에서 `node tests/gear-regression.cjs`, `node tests/growth-regression.cjs`, `node tests/pet-motion-regression.cjs`를 실행합니다. 외부 패키지 없이 장비/펫 거래·저장·메뉴 이벤트·동행 이동을 검사합니다.

브라우저 검사는 Playwright 설치 환경에서 `node tests/lobby-flow.cjs`, `node tests/lobby-accessibility.cjs`, `node tests/lobby-video.cjs`로 실행합니다. 기본 Chromium 또는 `CHROME_BIN`에 지정한 실행 파일을 사용하며 결과는 `test-results/`에 저장합니다.

착용 위치 검사는 로컬 웹 서버 실행 후 `GAME_URL=http://127.0.0.1:8769/ node tests/attachment-browser.cjs`로 실행합니다. 실제 그림 픽셀의 접촉을 확인하므로 file URL 대신 HTTP를 사용합니다.
